# ShopSmart Retail Sales Analysis

**AnalystLab Africa Experience Lab**

## Project Overview

This project analyses ShopSmart Retail's sales, customers, products, returns, stores, suppliers and inventory using Microsoft Excel. The objective is to turn raw retail data into actionable insights through data preparation, lookup formulas, PivotTables, charts, KPI cards and an executive dashboard.

## Business Problem

ShopSmart needs to understand which products and categories drive revenue, how sales vary over time and across stores, and where inventory and returns require management attention.

## Tools Used

- Microsoft Excel
- XLOOKUP and SUMIF formulas
- PivotTables and PivotCharts
- Interactive slicers
- Executive dashboard and business reporting

## Key Findings

- **Total revenue:** 7,575,250,086
- **Total orders:** 50,000
- **Total customers:** 5,000
- **Average order value:** 151,505
- **Leading category:** Beauty, generating 1,762,500,500 in revenue (approximately 23.27% of total revenue)
- **Reported return rate:** 5%
- **Reported inventory value:** 3,169,020,818

*Note: These figures are taken from the project dashboard and should be validated against the source calculations before being used for financial decisions. The currency unit was not confirmed.*

## Methodology

1. Imported the supplied retail datasets into Excel worksheets.
2. Used lookup formulas to connect orders with customers, products, stores and related records.
3. Analysed sales performance using PivotTables and charts.
4. Developed KPI cards and an executive dashboard with interactive filters.
5. Prepared business findings, recommendations, and data limitation notes.

## Important Data Limitations

The original Returns dataset does not directly identify the returned Product_ID. The Products and Suppliers datasets also do not provide a confirmed direct supplier-to-product relationship. Brand-name matching is therefore an assumption, not a verified supplier mapping. The dataset contains `Customer_Segment`, rather than the requested `Membership_Level`.
